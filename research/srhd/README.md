# Implicit adjoints of convergence loops: SRHD study

Scripts and raw results for the manuscript *Automatic implicit adjoints of convergence loops in CUDA kernels by source
transformation and their application to special-relativistic hydrodynamics*. Everything is regenerated by

```bash
bash research/srhd/reproduce_all.sh      # see the header for COMPARATORS, PY, JAXPY
```

The solver kernels themselves are in `examples/srhd/` (ordinary CUDA: `srhd.cu`, `srhd2d.cu`, `cooling.cu`) with their
host drivers; this directory holds the experiments. Raw results are written to `out/` (JSON/JSONL/NPZ); the figures to
`manuscript/implicit_srhd/figures/`.

## Environment of the reported runs

NVIDIA GeForce RTX 5080 (16 GB), driver 610.88, CUDA 12.8, WSL2 Ubuntu 22.04; GPU code compiled by Clang 19.1.7 for
sm_90 and JIT-compiled for the sm_120 device at load. Comparators: Enzyme v0.0.307 (ClangEnzyme-19 plugin), Clad v2.5,
JAX 0.6.2 with Optimistix 0.0.11. Double precision throughout.

## Notes

- `tolerance_sweep` is built with `-DCUAD_SOLVE_TOL=1e300`: it evaluates the adjoint at non-converged iterates on
  purpose, which the run-time check would otherwise refuse.
- Long L-BFGS-B runs on the GPU are not bitwise reproducible from run to run; the reconstruction errors of the
  noise-free runs vary in their second significant digit. GPU timings vary by a few percent (up to about 20 % for JAX).
- The noisy 2-D reconstruction stops by the discrepancy principle with the threshold tau * E[misfit] computed from the
  noise level alone (tau = 1.1), not from the true medium.
- `check_cooling.py` also runs a non-monotone cooling law (alpha = -0.5) where Newton's method fails in some cells and
  checks, in a child process, that the generated adjoint traps.
